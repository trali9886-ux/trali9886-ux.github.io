PDF-TO-TEST WORKFLOW

Generate a test from PDF

Choose one PDF. If it contains the questions, answer key and worked solutions, the editor matches and prepares the complete CBT test.

Accuracy and source status

A question-only PDF cannot prove its own answer key or worked explanation. The importer never invents either. When the uploaded PDF includes numbered answer and solution sections, the editor matches them to the questions and keeps source page images so equations and diagrams remain visible. This verifies the source mapping, not an independent re-solve.

Checking local OCR support…

Server converter: start python3 server.py --port 8081, then scan the selected question paper PDF with the higher-accuracy server-side converter.

The generated test starts as a local draft. Unique source-key and source-solution matches can be published through the existing CBT; unmatched answers or explanations require owner review. Source images preserve the original math and diagrams.
